# Strategic Architecture Decisions

## 3-Tier On-Device AI Architecture

### Tier 1: Apple Foundation Models (iOS/macOS 26+)
- Zero app-size cost, OS-provided ~3B text LLM
- `@Generable` macro for structured output (typed Swift structs)
- Use for: lab interpretation, health summaries, ABCDE explanations, clinical note structuring
- NOT for vision tasks (text-only)
- Service: `FoundationModelService.swift` (new)

### Tier 2: MLX MedGemma (Metal GPU)
- Primary chat engine with vision capability
- Upgrading from 4b-it to 1.5 (better derm SigLIP encoder)
- Handles: multi-turn chat, image analysis, longitudinal comparison
- Service: `LocalInferenceService.swift` (existing)

### Tier 3: CoreML on ANE (Neural Engine)
- Runs simultaneously with MLX on GPU (different hardware)
- Handles: segmentation, classification, image quality gating
- Service: `SkinClassificationService.swift` (existing)

### InferenceRouter
- New `InferenceRouter.swift` dispatches to correct tier
- Text-only structured -> Tier 1 (fallback to Tier 2)
- Vision+language -> Tier 2
- Lightweight vision -> Tier 3

## MedGemma 1.5 Upgrade
- No 4-bit MLX on HF yet (only bf16 at 9.94GB)
- Must quantize locally: `python -m mlx_vlm.convert --hf-path google/medgemma-1.5-4b-it --quantize --q-bits 4`
- Architecture identical (Gemma3ForConditionalGeneration) - MLX handles transparently
- NOT optimized for multi-turn (keep ChatSession but monitor quality)
- New capabilities: longitudinal imaging, bounding boxes, document understanding
- Legacy path fallback: check ~/skinai-models/medgemma-1.5/ then ~/skinai-models/medgemma/

## SceneKit -> RealityKit Migration
- 5 views: Bar3D, Skin3D, LesionReconstruction3D, Lesion4D, SpatialDistribution3D
- Use `RealityView` (SwiftUI native, no UIViewRepresentable needed)
- Remove `SceneViewRepresentable` protocol from PlatformCompat.swift
- Billboard text -> SwiftUI overlays via `content.project()` 3D-to-2D
- No orthographic camera in RealityKit -> use distant perspective
- OrbitState @Observable for drag-to-rotate gesture handling
- New helper file: `Utils/RealityKitChartHelpers.swift`

## Key Technical Constraints
- MLX.GPU.set(cacheLimit: 512MB) to prevent memory pressure
- Foundation Models session is ephemeral (no KV cache management needed)
- CoreML .computeUnits = .cpuAndNeuralEngine to avoid GPU contention with MLX
- RealityKit entities are @MainActor isolated
