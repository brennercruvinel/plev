# paletas (referencia)

fonte da verdade das cores. cada arquivo lista todos os hex de um tema, na ordem
original, com o tom (claro/medio/escuro) de cada cor. esta pasta e referencia, o
Zola nao a processa.

dos 11 temas curados, 6 estao ativos no site (aparecem no switcher) e 5 ficam
como arquivo. o tema `steel` foi renomeado para `logseq`. os accents que de fato
vao pro site estao em `sass/_palettes.scss`, escolhidos por contraste (ver
`kdb/adr/0001` e `kdb/adr/0002`); aqui ficam as rampas completas de origem.
