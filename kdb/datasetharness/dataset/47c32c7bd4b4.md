## Showcase dev patterns — learned 2026-03-22

### What worked
- Parallel subagents for batch edits (3 batches of 10 files each for h-full migration)
- Post-processing SVGs with darkifySvg() instead of CSS filter invert (invert breaks demos that already have dark DSL)
- Guard ALL ResizeObserver callbacks with `if (width < 1 || height < 1) return` — prevents crashes on mount
- `key={activeId}` on Demo component forces clean unmount/remount — fixes Strict Mode duplications
- devicon CSS font icons for automatic language logos

### Pitfalls to avoid
- CSS `filter: invert()` on Kroki SVGs breaks demos that already use dark colors in DSL (Graphviz, D2, PlantUML) — use darkifySvg() string replacement instead
- Tailwind 4 nested selectors like `[&_svg]:invert` may not generate correctly — use plain CSS classes in index.css
- ResizeObserver fires immediately with 0 dimensions before layout — ALWAYS guard
- `overflow-auto` on parent container prevents `h-full` from working in children — use `flex flex-col` + `flex-1 min-h-0` instead
- Cleanup inside `.then()` never executes as useEffect return — declare instance var outside, cleanup outside

**Why:** These patterns emerged from 3 rounds of debugging the same issues. Following them from the start saves hours.
**How to apply:** When creating ANY new demo, use the guard pattern, aborted flag, and darkifySvg() from day one.
