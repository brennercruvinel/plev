## Overview
PLEV is a GPU-first compositing engine in Rust targeting 6 platforms via wgpu.

## Key Architecture
- `src/gpu.rs` - wgpu context, pipelines (quad + text), projection uniform buffer
- `src/text.rs` - cosmic-text FontSystem + glyph atlas + shaping cache + persistent GPU buffers
- `src/compositor.rs` - SceneNode graph with FxHash dirty tracking + persistent GPU buffers
- `src/window.rs` - winit 0.30 ApplicationHandler, builds scene graph per frame
- `src/lib.rs` - module re-exports + WASM entry point
- `shaders/quad.wgsl` - colored quad rendering
- `shaders/text.wgsl` - textured quad (atlas sampling, R8Unorm alpha)

## Layer System (TASK-07)
- **Per-layer dirty tracking** via FxHasher — unchanged layers = zero GPU work
- **Compositor** manages `Vec<Layer>`, each with own SceneNodes, quad/text buffers, offscreen texture
- **Premultiplied alpha** throughout: shaders output `rgb*a, a`, blend `One/OneMinusSrcAlpha`
- **GpuVec** extracted to `src/gpu_vec.rs` — shared by compositor and text system

## API Notes (wgpu 28, cosmic-text 0.18)
- `DeviceDescriptor` requires `trace` and `experimental_features` fields
- `PipelineLayoutDescriptor` uses `immediate_size: 0` instead of `push_constant_ranges`
- `RenderPipelineDescriptor` uses `multiview_mask: None` instead of `multiview`
- `RenderPassDescriptor` requires `multiview_mask: None`
- `RenderPassColorAttachment` requires `depth_slice: None`
- `cosmic_text::Buffer::set_text` takes `&Attrs` (reference) + extra `Option<Align>` param
