# Emotional Seeds Core — Architecture Details

## Module Dependency Graph
```
embedding.rs ← seed.rs ← entity.rs
                  ↑          ↑
                  |     roda.rs
                  |
           state_space.rs → hmm.rs → cycle.rs
                  |
           similarity.rs
                  |
           user_model.rs (uses decay.rs + embedding.rs)
                  |
              decay.rs
```

## Data Flow
```
Raw Input (voice/text/facial/interaction/user-report)
    → Speranto LLM (on-device, 4B params)
    → EmotionalEmbedding (N-dim vector)
    → PADProjection → PADVector (3-dim, for viz)
    → EmotionalSeed (with contexts, entities, roda areas)
    → EmotionalStateSpace.assign_seed() → ClusterId
    → EmotionalHMM.observe_transition() → predictions
    → CycleDetector.observe() → addiction cycle detection
    → RelationalImpactGraph.ingest_seed() → entity impact
    → RodaTracker.ingest_seed() → life area scores
    → UserModel.confirm()/deny() → personalized weights
```

## Key Types
- `EmotionalEmbedding`: Vec<f32> of N dimensions (primary representation)
- `PADVector`: {pleasure, arousal, dominance} in [-1,1] (derived, for UI)
- `EmotionalSeed`: The fundamental data unit (embedding + PAD + weight + confidence + contexts)
- `Entity` + `EntityKind`: People, apps, substances, habits, etc.
- `ClusterId`: u32 index into k-means centroids (Markov states)
- `EmotionalCycle`: Detected recurring pattern (e.g., addiction loop)
- `RodaArea`: The 8 Wheel of Life dimensions
- `UserModel`: Per-user learned parameters (PAD weights, decay config)

## Integration Points with Other Products
- **Hoff Listening**: Seeds from voice → entity extraction → RelationalImpactGraph
- **Tracker de Vícios**: CycleDetector for addiction patterns (App entities)
- **Cozinha**: Micro-seeds from task completion, Medication entities
- **Super Aurora**: Content entities, child-mode PAD weights
- **SkinAI**: Clinical situation entities, stress↔skin correlation
- **Roda da Vida**: RodaTracker with cross-area correlation
- **Eutimia**: All seed data encrypted at rest, face=key to decrypt
