> ## contexto
> 
> o plev tem 15k loc de engine gpu-first com todos os primitivos necessarios (rounded rects via pathbuilder, texto, input editavel, animacoes, signals, layout flexbox, efeitos). mas nao tem nenhuma interface real construida. ninguem abre o projeto e ve algo que parece um framework de ui -- ve demos tecnicos soltos. o brenner quer que ao rodar `cargo run --example widget_showcase`, a reacao seja "isso substitui flutter/egui/react."

> ## widgets por categoria
> 
> ### 1. buttons (~220 loc)
> - **4 variantes em row**: primary, secondary, danger, ghost
> - **hover**: tween<f32> 0->1, 150ms easeoutcubic. cor lerp entre base e hover_color
> - **press**: fake scale -- desenha 2px menor em cada lado + offset 1px. spring<f32> para bounce-back
> - **disabled**: alpha 0.4, nao responde a hover/click
> - **labels**: "primary", "secondary", "danger", "ghost"
> 
> ### 2. inputs (~180 loc)
> - **search bar**: textinput com icone magnifying glass (circle stroke + line stroke path)
> - **standard input**: textinput com placeholder
> - **label + input pairs**: texto "email" acima, input abaixo
> - forward de keyboard para input focado, tab para ciclar
> 
> ### 3. selection controls (~300 loc)
> - **3 checkboxes**: rounded rect stroke (border) / filled (checked). checkmark via pathbuilder 2-segment line stroke. animacao: opacity tween 0->1 easeoutback 200ms
> - **2 toggles**: track pill (rounded_rect radius=h/2). knob circle com spring<f32> (stiffness=200, damping=15). track color lerp off->on baseado no spring value
> - **3 radio buttons**: circle stroke outer. circle fill inner com tween<f32> scale. selecao exclusiva
> 
> ### 4. display (~250 loc)
> - **2 cards**: shadow fake (2 offset rounded rects) + rounded rect bg + titulo + body text. profundidades diferentes (elevated vs flat)
> - **badges**: 4 pills coloridos (info azul, success verde, warning amarelo, danger vermelho). rounded rect com radius=h/2 + texto centralizado
> - **progress bar**: track dark rounded rect + fill colored rounded rect. tween<f32> com repeat::infinite + reverse, 3s, easeinoutcubic
> - **avatars**: 3 circulos coloridos com iniciais de texto dentro + small green dot (online indicator)
> 
> ### 5. feedback (~200 loc)
> - **3 alert banners**: rounded rect bg + accent bar esquerda (4px) + icone area + texto. info/warning/error. dismiss x button com opacity tween
> - **loading spinner**: circle stroke (track, muted). arc parcial stroke (accent) rotacionando. `spinner_angle += dt * tau` continuo

> ## animacao
> 
> | efeito | tipo | params |
> |---|---|---|
> | hover buttons/sidebar | tween<f32> | 0.15s, easeoutcubic |
> | button press | spring<f32> | stiffness=300, damping=20 |
> | toggle slide | spring<f32> | stiffness=200, damping=15 |
> | checkbox check | tween<f32> | 0.2s, easeoutback |
> | radio dot | tween<f32> | 0.15s, easeoutcubic |
> | progress fill | tween<f32> | 3.0s, easeinoutcubic, repeat+reverse |
> | spinner | raw angle | dt * 4.0 rad/s |
> | alert dismiss | tween<f32> | 0.2s, easeoutcubic |
> 
> todas tickadas em render() via `clock.tick()`. request_redraw continuo enquanto qualquer animacao ativa.
