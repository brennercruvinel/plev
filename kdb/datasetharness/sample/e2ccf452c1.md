# workflow plev-fix-demos

trajetoria agentica encodada como codigo: um workflow de orquestracao em js que
conserta as demos da galeria do plevguardian, uma por uma. quatro turns logicos,
intencao do orquestrador, agente de scan, pipeline de agentes de fix, e o resumo
agregado. duas fases programaticas (scan, fix), cada uma disparando agente.

## a intencao

cada demo da galeria tem que renderizar fiel e ter um thumbnail real. o workflow
roda em duas fases. scan acha as demos com thumbnail quebrado (preto, chapado ou
faltando), medindo brilho medio e desvio padrao do grayscale com PIL: quebrado se
std<8 ou mean<18 ou mean>248, ou o arquivo nao existe. fix dispara um agente por
demo, com regra never-worse: nunca instala thumbnail em branco, nunca toca no
demos.json, so mexe no diretorio da propria demo.

as quebras tipicas vem de dependencia faltando, e e a causa numero um. addon do
three (OrbitControls, OBJLoader, GLTFLoader, EffectComposer), plugin do gsap
(ScrollTrigger, SplitText, Draggable), clipboard, p5, matter, pixi, tone. o fix
injeta o script da versao certa e depois baixa local pra nao depender de cdn
remoto, re-renderiza e remede.

a regra dura que amarra tudo: trabalhar so dentro de `${GUI}`, editar so o
diretorio da demo alvo, nunca chamar delete/put da api da galeria, nunca
reiniciar ou matar o server (roda na :8080), backup do index.html no /tmp antes de
editar.

## o codigo (verbatim)

```js
export const meta = {
  name: 'plev-fix-demos',
  description: 'Per-demo: compile preprocessors, clone missing deps/assets locally, fix broken render, regen validated thumbnail. One agent per demo, never-worse, never touches demos.json.',
  phases: [
    { title: 'Scan', detail: 'find demos with blank/broken thumbnails' },
    { title: 'Fix', detail: 'one agent fixes each demo + installs a real thumb' },
  ],
}

const GUI = '/Volumes/HOFF/dev/plevguardian/fet/gui'

const SCAN_SCHEMA = {
  type: 'object',
  additionalProperties: false,
  required: ['dirs'],
  properties: { dirs: { type: 'array', items: { type: 'string' } } },
}

const FIX_SCHEMA = {
  type: 'object',
  additionalProperties: false,
  required: ['dir', 'renders', 'thumbInstalled'],
  properties: {
    dir: { type: 'string' },
    fixesApplied: { type: 'array', items: { type: 'string' } },
    renders: { type: 'boolean' },
    thumbInstalled: { type: 'boolean' },
    note: { type: 'string' },
  },
}

const SAFETY = `HARD RULES:
- Work ONLY in ${GUI}. Edit ONLY files inside the target demo's OWN directory.
- NEVER modify/delete ${GUI}/demos.json, other demos, or anything outside the demo dir.
- NEVER call any gallery DELETE/PUT API and NEVER restart/kill the server (it runs on :8080).
- Back up the demo's index.html to /tmp before editing. Never install a blank thumbnail (never-worse).`

phase('Scan')
const scan = await agent(
  `${SAFETY}\nIn ${GUI}, list every demo whose current thumbnail is blank/black/flat (a broken preview). Run python3 with PIL over demos.json: for each demo, open thumbs/<dir>.jpg, convert L, compute mean brightness and stddev; a thumbnail is BROKEN if std<8 OR mean<18 OR mean>248, or the file is missing. Return the list of broken demo dirs.`,
  { label: 'scan-bad-thumbs', phase: 'Scan', schema: SCAN_SCHEMA, agentType: 'Explore' },
)
const dirs = (scan && scan.dirs ? scan.dirs : []).filter(Boolean)
log(`Found ${dirs.length} demos with broken thumbnails to fix`)

phase('Fix')
const results = await pipeline(
  dirs,
  (dir) =>
    agent(
      `${SAFETY}

You are making ONE gallery demo render faithfully and produce a REAL thumbnail.
DEMO dir: ${dir}  (gallery server: http://localhost:8080)

STEPS (do them, don't just describe):
1. cd ${GUI}. Find the demo's served index.html: try ${dir}/dist/index.html then ${dir}/src/index.html then ${dir}/index.html. Note its served path (e.g. ${dir}/dist/index.html). Back it up: cp it to /tmp/wfbak-${dir}.html.
2. Run: node fix-fidelity.js ${dir}   (compiles any raw SCSS->CSS and downloads external http(s) assets/scripts/libs into the demo's dist/assets, rewriting refs local).
3. Render + measure a thumbnail:
   python3 .thumb-gen.py "http://localhost:8080/<servedpath>" /tmp/wf-${dir}.jpg 6000
   then measure with python3+PIL (mean brightness + stddev of grayscale). REAL preview = std>8 and 8<mean<248.
4. If still blank/flat, READ the index.html and diagnose missing dependencies (the #1 cause). Common CodePen breakages and fixes (inject the matching <script> right after the lib it extends, or in <head>):
   - "THREE.OrbitControls"/"THREE.OBJLoader"/"THREE.GLTFLoader"/"THREE.EffectComposer" used but addon not loaded -> inject the version-matched three addon, e.g. for three r128: https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/controls/OrbitControls.js (match the loaded three version; check the three <script> src for the version).
   - "new Clipboard(" -> https://cdn.jsdelivr.net/npm/clipboard@2/dist/clipboard.min.js
   - GSAP plugins (ScrollTrigger/SplitText/Draggable) used but not loaded -> inject from cdnjs gsap of the matching version.
   - p5 / matter / pixi / tone etc. referenced but missing -> inject the matching CDN script.
   - Raw SCSS still present -> ensure step 2 compiled it (node has 'sass').
   Then download that injected script locally too (re-run node fix-fidelity.js ${dir}) so it's not a remote dependency. Re-render + re-measure.
5. If the thumbnail now shows real content: cp /tmp/wf-${dir}.jpg ${GUI}/thumbs/${dir}.jpg . If it NEVER renders (deleted pen / WebGPU headless-black), leave the existing thumb and note the reason - do NOT install a blank.
6. Verify ${GUI}/demos.json is byte-identical to before (you must not have touched it).

Return the status object.`,
      { label: `fix:${dir}`, phase: 'Fix', schema: FIX_SCHEMA },
    ).catch(() => ({ dir, renders: false, thumbInstalled: false, note: 'agent error' })),
)

const ok = results.filter((r) => r && r.thumbInstalled)
log(`Fixed thumbnails installed: ${ok.length}/${dirs.length}`)
return {
  totalBroken: dirs.length,
  thumbsFixed: ok.length,
  results: results.filter(Boolean).map((r) => ({ dir: r.dir, renders: r.renders, thumbInstalled: r.thumbInstalled, fixes: r.fixesApplied || [], note: r.note || '' })),
}
```
