{# hreflang alternates. declares every translated version of the current page to search engines and points x-default at the default-language version. avoids duplicate-content ambiguity across languages. only emitted for page/section contexts (taxonomy pages do not expose translations in zola). #} {%- if page or section -%} {%- set current = page | default(value=section) -%} {%- set current_lang = current.lang | default(value=config.default_language) -%} {%- if current_lang == config.default_language %} {%- endif %} {%- for translation in current.translations | default(value=[]) %} {%- if translation.lang == config.default_language %} {%- endif %} {%- endfor %} {%- endif -%}
