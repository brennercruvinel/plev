UNAVI (unavi.xyz (https://unavi.xyz)) é uma plataforma open-source e peer-to-peer para espaços 3D, pensada como infraestrutura aberta para a "internet espacial". github (https://github.com/unavi-xyz/unavi)

O que faz

A proposta central é permitir criar e habitar ambientes 3D sem precisar de conta ou servidor centralizado. Você pode entrar usando um headset VR para presença completa ou acessar pelo desktop. O projeto foi construído principalmente em Rust com a engine Bevy, e o código fica disponível publicamente no GitHub. github (https://github.com/unavi-xyz/unavi)

Aspectos técnicos relevantes

O stack é todo baseado em protocolos abertos e arquitetura P2P, o que significa que não há uma empresa controlando os servidores ou os dados dos mundos criados. Alguns dos módulos em desenvolvimento incluem suporte a VR, portais estáticos e dinâmicos, objetos dinâmicos, editor de mundos e multiplayer. É essencialmente uma tentativa de construir o metaverso de forma descentralizada, sem os walled gardens de plataformas como Meta Horizon ou Roblox. github (https://github.com/unavi-xyz/unavi)

Contexto de mercado

Projetos assim competem com iniciativas como o Open Metaverse Interoperability Group e plataformas como Webaverse ou Vircadia, todas apostando que a internet espacial deve ser regida por padrões abertos em vez de ecossistemas proprietários. github (https://github.com/unavi-xyz/unavi)
