## context

what is true today and why it does not hold: the code (`path:line`), the
measurement, the bug. nothing a reader has to take on faith.

## decision

what changes, as rules the code will follow. one decision per record.

## consequences

what this makes easy, what it makes hard, what it rules out, and how a
test or a gate keeps it true.

## alternatives

what was weighed and why it lost.
